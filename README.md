# Консольный менеджер задач

Учебный проект на C++20. Позволяет вести список задач с сохранением в текстовый файл. 
Поддерживает создание, редактирование, удаление задач, отслеживание статуса и даты создания.

## Возможности

- Создание нового файла или открытие существующего
- Добавление задач с автоматической фиксацией даты и времени
- Изменение текста задачи
- Переключение статуса (Не выполнено / Выполнено)
- Удаление задач с автоматической перенумерацией
- Автосохранение после каждого действия
- Обратная совместимость со старым форматом файлов

## Требования

- Windows
- Visual Studio 2022 (или другой компилятор с поддержкой C++20)
- Стандарт C++20 (`/std:c++20`)

## Сборка и запуск

1. Откройте проект в Visual Studio 2022 или создайте новый консольный проект и добавьте файл `main.cpp`
2. В свойствах проекта: C/C++ → Language → C++ Language Standard → **ISO C++20 Standard (/std:c++20)**
3. Соберите проект (Ctrl+Shift+B)
4. Запустите исполняемый файл

## Использование

При запуске программа предложит:
- **1** — открыть существующий файл с задачами
- **2** — создать новый файл

Далее доступны команды:
- **1** — добавить задачу
- **2** — изменить текст задачи
- **3** — изменить статус задачи
- **4** — удалить задачу
- **5** — выйти из приложения

## Формат файла

Задачи хранятся в текстовом файле в формате:

`текст задачи|статус|дата и время`

Пример:

`Купить хлеб|Не выполнено|26.05.2026 14:35`
`Позвонить врачу|Выполнено|25.05.2026 10:12`
